==================================================
MAIN GOAL
==================================================

Transform MarketFlow ERP from a fixed-role demo ERP into a real SaaS ERP platform where:

1. There is one global platform owner: Super Admin.
2. Super Admin manages all stores/companies/tenants.
3. Any user can create a new store/company and start a free trial.
4. Free trial duration is 10 days by default.
5. Super Admin can extend, reduce, cancel, or reset the trial duration for any store.
6. Super Admin can activate, deactivate, suspend, archive, delete, or restore stores.
7. Store data should remain saved when the store is deactivated or suspended.
8. Each store has one Owner.
9. Store Owner can create users.
10. Store Owner can create custom roles with any name.
11. Store Owner can assign exact page permissions and action permissions to each role.
12. Remove the idea of fixed hardcoded roles such as Admin, Manager, Cashier, Accountant as the main permission system.
13. Roles should become dynamic and customizable per store.
14. Every page, button, action, modal, invoice, report, CRUD operation, and backend endpoint must respect permissions.
15. Every page must have proper UI/UX states:
    - loading
    - error
    - empty state
    - success state
    - validation state
    - forbidden state
16. Every backend and frontend error must be handled safely.
17. No page should crash the whole app.
18. No fake buttons.
19. No fake CRUD.
20. No fake dashboard numbers.
21. No frontend-only data mutation for business data.
22. All business data must be stored in PostgreSQL and accessed through real APIs.

==================================================
NEW BUSINESS MODEL
==================================================

This project should become a SaaS ERP system.

There are two levels:

A) Platform Level
This is controlled by Super Admin.

Super Admin can:
- See all stores/companies/tenants.
- Create a store manually.
- View store details.
- Activate a store.
- Deactivate a store.
- Suspend a store.
- Delete a store.
- Restore a deleted store if using soft delete.
- View trial stores.
- View paid stores.
- View expired trial stores.
- View suspended stores.
- Manage subscription packages/plans.
- Assign a store to a package.
- Change store package.
- Extend trial period.
- Reduce trial period.
- End trial immediately.
- Restart trial if needed.
- Convert trial store to paid store.
- View invoices/subscriptions/payments for stores.
- View store usage:
  - users count
  - products count
  - sales count
  - storage/database usage if possible
  - last login
  - last activity
- Login/impersonate store owner safely if needed, with audit log.
- View system logs.
- View failed API requests.
- View platform audit logs.
- Control global settings.
- Control default trial duration.

B) Store Level
This is controlled by Store Owner.

Store Owner can:
- Manage store profile.
- Manage branches.
- Manage employees/users.
- Create custom roles.
- Name roles freely.
- Assign pages to roles.
- Assign actions to roles.
- Assign users to roles.
- Assign users to branches.
- Control who can view/add/edit/delete/export/print/approve/refund/receive.
- Manage ERP data based on permissions.

Important:
The Store Owner is not just a normal role.
The Store Owner is the tenant owner and always has full access inside their own store unless Super Admin suspends the store.
