# برومبت تصميم نظام ERP للسوبرماركتس والبقالات

## اسم النظام

**MarketFlow ERP**

---

## الهدف العام

صمّم وطور واجهة Web App كاملة لنظام ERP احترافي مخصص لإدارة السوبرماركتس والبقالات ومحلات التجزئة.

النظام يجب أن يكون باللغة العربية بالكامل ويدعم اتجاه الكتابة من اليمين إلى اليسار **RTL**، مع إمكانية إضافة اللغة الإنجليزية لاحقًا.

التصميم يجب أن يكون حديثًا جدًا، نظيفًا، سريعًا، عمليًا، ومناسبًا للاستخدام اليومي للكاشير والإدارة، ويجمع بين البساطة والقوة.

---

## التقنيات المطلوبة

استخدم التقنيات التالية في التصميم والواجهة:

- React.js أو Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI
- GSAP Animations
- Three.js أو React Three Fiber
- Framer Motion عند الحاجة
- Responsive Design للموبايل والتابلت والديسكتوب
- Dark Mode و Light Mode
- RTL Arabic Layout

# فكرة الأنيميشن العامة

استخدم GSAP و Three.js بطريقة احترافية بدون مبالغة.

## Three.js

في صفحة البداية والداشبورد استخدم مشهد 3D بسيط يحتوي على:

- عربة تسوق 3D
- منتجات صغيرة Floating
- Barcode Scanner صغير
- صناديق مخزون
- حركة دوران بطيئة
- إضاءة ناعمة
- Particles خفيفة في الخلفية

مهم جدًا:

- لا تجعل الـ 3D يبطئ النظام
- اجعل مشاهد Three.js تعمل Lazy Loaded
- لا تستخدم 3D في صفحات التشغيل الحساسة مثل POS إلا بشكل خفيف جدًا

## GSAP

استخدم GSAP في:

- دخول الكروت في الداشبورد
- انتقال الصفحات
- ظهور القوائم الجانبية
- Counters للأرقام والإحصائيات
- Animation عند انخفاض المخزون
- Animation عند إتمام عملية بيع
- Loading transitions
- Hover micro-interactions

# توزيع الأدوار والصلاحيات

صمم Role Based Access Control واضح.

---

## Owner

صلاحيات كاملة:

- رؤية كل الفروع
- الأرباح والخسائر
- التقارير المالية
- إضافة وحذف المستخدمين
- إدارة الصلاحيات
- التحكم في النظام بالكامل
- إدارة الإعدادات العامة
- رؤية سجل النشاط بالكامل

---

## Admin

- إدارة المنتجات
- إدارة المخزون
- إدارة الموظفين
- رؤية التقارير العامة
- إدارة الفروع
- لا يستطيع حذف بيانات مالية حساسة إلا بإذن

---

## Branch Manager

- إدارة فرع واحد فقط
- متابعة المبيعات
- متابعة الكاشير
- متابعة المخزون
- طلب مشتريات
- تقارير الفرع
- إدارة شفتات الموظفين داخل الفرع

---

## Cashier

- استخدام POS فقط
- إنشاء فاتورة بيع
- تطبيق خصم حسب صلاحية محددة
- طباعة فاتورة
- تعليق فاتورة
- إنشاء مرتجع حسب الصلاحيات
- لا يرى الأرباح أو التقارير المالية

---

## Inventory Manager

- إضافة وتعديل المنتجات
- متابعة الكميات
- الجرد
- تحويل مخزون بين الفروع
- تنبيهات المخزون الناقص
- تسجيل الهالك
- متابعة تواريخ الصلاحية

---

## Purchasing Officer

- إنشاء أوامر شراء
- التعامل مع الموردين
- متابعة فواتير الشراء
- تسجيل البضاعة الواردة
- متابعة عروض أسعار الموردين

---

## Accountant

- المصروفات
- الأرباح والخسائر
- تقارير الضرائب
- تقارير المبيعات
- المدفوعات
- حسابات الموردين
- لا يستطيع تعديل المنتجات

---

## Supplier Viewer

- يرى طلبات الشراء الخاصة به فقط
- يرفع عروض الأسعار
- يرى حالة الطلب
- يرى المدفوعات الخاصة به فقط

- استخدم Toast notifications
