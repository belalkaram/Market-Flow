PHASE 7 — BUSINESS LOGIC
==================================================

Implement basic ERP business rules:

Inventory:
- Stock decreases after POS checkout.
- Stock increases after receiving purchase order.
- Stock adjustment creates stock movement.
- Low stock alerts based on minimum quantity.
- Product cannot be sold if stock is insufficient unless admin override permission exists.

Sales:
- Sale order calculates subtotal, tax if applicable, discount, total.
- Payment method is stored.
- POS transaction generates receipt number.
- Refund creates reverse stock movement where applicable.

Purchasing:
- Purchase order has statuses:
  draft, submitted, approved, received, cancelled
- Receiving purchase order updates inventory.
- Each purchase item has quantity, unit cost, total.

Tasks:
- Task has priority:
  low, medium, high, urgent
- Task has status:
  pending, in_progress, completed, cancelled
- Assigned user must belong to same tenant.
- Branch-specific task must be visible only to branch users or admins.

RBAC:
- Owner/Admin can manage all demo data.
- Branch Manager can manage branch data.
- Cashier can use POS and see own transactions.
- Inventory Manager can manage stock and products.
- Purchasing Officer can manage suppliers and purchases.
- Accountant can view financial records.
- Sales Rep can manage customers and sales-related records.
